智能体中间表示（S-IR）定义

1. 基础元素定义
（1）变量域抽取规则

变量分为 3 类，由 Agent 实时从运行上下文抽取，无需预定义：

  • Vin：输入变量 → 从当前工具入参中抽取
  • Vout：输出变量 → 从工具返回结果中抽取
  • Vctx：全局上下文变量 → 环境信息抽取

抽取规则：

EXTRACT(var, source, description)
（2）指令语法
program    ::= stmt*
stmt       ::= EXTRACT(var, source, desc)
            | CALL(tool, input_vars)
            | ASSERT(P_rule)
            | IF(Q_rule) THEN SAT_BRANCH ELSE UNSAT_BRANCH
            | JMP(label)
            | LABEL(label)
            | RETURN
（3）语义说明
  • EXTRACT：运行时抽取变量
  • IF(Q_rule)：安全约束判断
  • ELSE：风险触发 + 自动回滚
  • 整体为 Agent 动态生成的安全执行代码
